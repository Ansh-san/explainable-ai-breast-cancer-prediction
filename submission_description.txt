For this project, I investigated how an AI model makes predictions by applying explainable AI techniques to the support vector machine developed in Week 3. The model classifies breast-mass records as benign or malignant using the publicly available Wisconsin Diagnostic Breast Cancer dataset. I reconstructed the same preprocessing and classification pipeline using the original stratified training split and selected hyperparameters. The reconstructed model achieved 99.12% accuracy and 98.80% malignant F1 on the same 114-record test set, including one false negative.

I applied two complementary interpretation methods. First, I used permutation feature importance to measure how much the model's malignant F1 score changed when each feature was shuffled. Each feature was shuffled 30 times, and the mean decrease and variation were plotted. Worst texture had the largest observed mean F1 decrease of 0.0731 on this test set. These findings describe the model's reliance on the features under the selected evaluation procedure; they do not establish medical causation.

Second, I used Kernel SHAP to explain three individual predictions: a false negative, a true positive and a true negative. I selected a stratified background of 40 training records and explained the model's signed decision score, which is not a probability. The report includes visualizations of the false-negative and true-positive explanations. I also repeated the false-negative explanation with a second training background. Four of the five largest contributing features overlapped, showing that the reference choice can affect local explanations even when the prediction remains unchanged.

The report discusses how global and local explanations can support error investigation, documentation, human oversight and accountability. It also addresses correlated features, explanation uncertainty, potential bias, data limitations and the need for independent validation. The accompanying commented Python code recreates the analysis and generates the figures and result files. This project is for educational purposes only and must not be used for clinical diagnosis.
